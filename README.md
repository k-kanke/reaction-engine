# Reaction Engine

## Chrome Extension

Download the latest packaged extension:

[Download reaction-engine-extension.zip](https://github.com/k-kanke/reaction-engine/releases/latest/download/reaction-engine-extension.zip)

### Install

1. Download `reaction-engine-extension.zip`.
2. Unzip it.
3. Open `chrome://extensions` in Chrome.
4. Enable Developer mode.
5. Click Load unpacked.
6. Select the unzipped extension folder.
7. Open Google Meet, then open the Reaction Engine side panel.

The zip is updated by GitHub Actions when extension files are merged to `main`.
